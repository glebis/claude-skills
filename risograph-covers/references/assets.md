# Asset provenance

Print textures were reused from the user's Goal Driven AI presentation, via the Hello Wiki deck's assets. Original source: the user's salience-lab-draft/gpt6/assets/images collection. Ownership and redistribution rights have not been independently verified; keep this package local until checked before public release.

Font binaries were copied from the same presentation: Manrope bold/extra-bold, EB Garamond regular/italic, and IBM Plex Mono medium. The original deck labels them as self-hosted Google Fonts. These fonts require their upstream licence notices for redistribution; this local package is not yet a licence-cleared public bundle.

The LinkedIn mark is an inline vector. Use it only to identify the profile, not to imply affiliation. The graph layout is editable illustration, not factual data unless explicitly sourced.

Paper Mono variable webfont was supplied by the user from Downloads/paper-mono-v1.000/fonts/webfonts/PaperMono[wght].woff2. It replaces IBM Plex Mono in the visual editor and footer. Public redistribution remains subject to its included licence.

Toolbar icons: Lucide v0.555.0 (Undo2, FolderOpen, Save, ImageDown) from the locally installed lucide-react library. SVG paths are embedded in the template. ISC / Feather MIT notices are preserved in assets/lucide-LICENSE.txt.
